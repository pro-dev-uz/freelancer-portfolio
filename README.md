# DevPro — Freelancer Portfolio Website

Modern responsive portfolio website for a freelance IT developer. Built with React + Vite, deployed on Railway with custom domain pro-dev.uz.

## Live Demo

**Website:** [pro-dev.uz](https://pro-dev.uz)  
**GitHub:** [pro-dev-uz/freelancer-portfolio](https://github.com/pro-dev-uz/freelancer-portfolio)

## Features

- Multi-language (Uzbek, Russian, English)
- Dark/Light mode
- Animated sections (Framer Motion)
- Services, Portfolio, FAQ, Contact form sections
- Fully responsive

## Tech Stack

- React 19, Vite 7, Tailwind CSS 4, Framer Motion
- Deployed on Railway.app (PaaS)

## Local Setup

```bash
git clone https://github.com/pro-dev-uz/freelancer-portfolio.git
cd freelancer-portfolio
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build   # Production build
npm run start   # Start with serve
```

Railway auto-builds on push. Custom domain connected via DNS A record.
